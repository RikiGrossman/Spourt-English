# Spourt English 🇬🇧

אפליקציה ללימוד אנגלית לדוברי עברית, בסגנון דואולינגו: מסלול לימוד של יחידות ושיעורים, שנפתחים אחד אחרי השני.

## מה יש כרגע (שלב 1 – בסיס)

- **מסלול לימוד** – יחידות עם שיעורים. כל שיעור נפתח רק אחרי שמסיימים את השיעור שלפניו.
- **4 סוגי תרגילים**, שנוצרים אוטומטית מאוצר המילים של השיעור:
  - בחירה מרובה (מילה בעברית → אנגלית ולהפך)
  - התאמת זוגות
  - בניית משפט מבנק מילים (עברית → אנגלית, אנגלית → עברית)
  - האזנה – שומעים משפט באנגלית ובונים אותו (כולל השמעה איטית 🐢)
- **לבבות** ❤️ – טעות עולה לב, ולב חדש מתמלא כל 30 דקות. תרגיל שטעו בו חוזר בסוף השיעור.
- **נקודות XP**, **רצף ימים** 🔥 ו**יעד יומי**.
- ההתקדמות נשמרת בדפדפן (localStorage).
- הגייה באנגלית בעזרת הקול המובנה בדפדפן (Web Speech API).

## הרצה

```bash
npm install
npm run dev      # שרת פיתוח
npm test         # בדיקות
npm run build    # בנייה לפרודקשן
```

## מבנה הפרויקט

```
src/
  data/course.ts        תוכן הקורס – יחידות, שיעורים, מילים ומשפטים
  lib/exercises.ts      יצירת תרגילים מתוך תוכן השיעור
  lib/answer.ts         בדיקת תשובות (מתעלם מאותיות גדולות, פיסוק וניקוד)
  lib/progress.ts       לבבות, XP, רצף ופתיחת שיעורים
  lib/store.ts          שמירת ההתקדמות
  components/           מסכים ותרגילים
```

## הוספת תוכן

כדי להוסיף שיעור, מוסיפים אותו ל־`src/data/course.ts` עם מילים (`words`) ומשפטים (`sentences`).
התרגילים נוצרים ממנו אוטומטית. ל־`alt` אפשר להוסיף תשובות נוספות שיתקבלו (למשל `I'm` במקום `I am`).

## הצעדים הבאים

- הרבה יותר תוכן (זמנים, שאלות, מספרים, צבעים, מקומות…)
- תרגיל דיבור עם זיהוי קול
- תרגול חוזר חכם (חזרה מרווחת) על מילים שנשכחו
- חשבונות משתמש וסנכרון בין מכשירים
- התקנה כאפליקציה בטלפון (PWA)
