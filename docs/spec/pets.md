# חיה אישית 🐾

לכל לומד יש חיה אישית שמלווה אותו לאורך הלמידה ומייצגת את האפליקציה מולו. החיה **לא מלמדת** – היא מחמיאה על הישגים, מגיבה להתקדמות, מציעה אתגרים, שולחת את התזכורות היומיות ומעודדת התמדה. ככל שהלומד מתקדם היא מתפתחת, מקבלת אביזרים ופותחת יכולות.

הקוד: `src/lib/pet.ts` (לוגיקה טהורה + `usePet`), `src/components/pet/`, `shared/pet-design.ts` (עיצוב פרימיום), `server/src/routes/pet.ts` ו־`supabase/functions/pet-design/` (עיצוב עם AI).

## מה נבנה (שלב 1)

| רכיב | איך זה עובד |
|---|---|
| אימוץ | מכרטיס החיה במסלול: בוחרים אחת מ־4 חיות (דרקון, ינשוף, נמר, חד־קרן) ונותנים שם. מי שמאמץ באמצע הדרך מתחיל בשלב שלו, עם האביזרים שכבר הרוויח. |
| שלבים | לפי XP: ביצה (0) → גור (10, בוקעת בשיעור הראשון) → מתבגר (200) → בוגר (600) → אגדה (1500). כל שלב משנה את המראה, ובכל התפתחות החיה מביאה 20 × השלב יהלומים. |
| אביזרים | 9 אביזרים שנפתחים באבני דרך (שיעור ראשון, רצף 3/7/14/30, 10/30 שיעורים, 500/2000 XP). נשארים גם אם הרצף נשבר. לובשים/מורידים במסך החיה, אחד לכל מקום (ראש, פנים, צוואר). |
| יכולות | מחמאות ותזכורות אישיות (גור), אתגר יומי (מתבגר), טריקים בהקשה (בוגר), הילה אגדית שמכפילה את פרס האתגר (אגדה). |
| תגובות | אחרי כל שיעור/חזרה החיה מגיבה במסך הסיום – התפתחות, אתגר שהושלם, אביזר חדש, יעד יומי, שיעור בלי טעויות – בסגנון האישיות שלה (שמחה, רגועה, מצחיקה, אמיצה). |
| אתגר יומי | אחד מ־5 אתגרים לפי התאריך (למשל 3 שיעורים, 2 שיעורים בלי טעות, 60 XP). פרס 15–30 יהלומים, פעם ביום. |
| תזכורות | באנדרואיד, מרגע שיש לחיה יכולת "תזכורות אישיות", ההתראות היומיות נשלחות בשמה ובקולה. |
| שיתוף | כפתור שיתוף (Web Share, או העתקה ללוח) עם טקסט על החיה, השלב וה־XP; קישור לליגה השבועית. |
| פרימיום | מנויי פרימיום מעצבים חיה ייחודית: מראה (20 חיות), צבע, עד 3 תכונות מיוחדות, אישיות ותיאור – ידנית, או בתיאור חופשי ל־AI (`POST /api/pet/design`, ראו [api.md](../api.md)). אפשר לחזור לחיה המקורית בכל רגע. |

החיה נשמרת ב־localStorage בלבד (`spourt-english:pet:v1`), כמו היהלומים, כך שחוזה ההתקדמות מול השרת לא השתנה. איפוס התקדמות מחזיר את החיה לביצה ושומר את הסוג, השם והעיצוב.

החיה מדברת בלשון נקבה ("החיה"), והפנייה ללומד בלשון רבים, כמו בשאר האפליקציה.

## מה עוד לא נבנה (שלב 2 – דורש שרת)

- **סנכרון החיה בין מכשירים**: שמירה בחשבון (טבלה ב־Supabase ו־SQLite, ומיזוג כמו ב־progress).
- **החיה בליגה ובפרופיל ציבורי**: הצגת החיה של כל משתתף בלוח המובילים – שינוי ב־`shared/api.ts` (`LeaderboardEntry`), בשרת וב־Supabase.
- **תחרויות בין משתמשים**: אתגר שבועי ראש בראש בין חברים (מי צובר יותר XP), עם פרס לחיה של המנצח.
- **משימות קבוצתיות ופרסים משותפים**: קבוצה (משפחה/כיתה) עם יעד XP שבועי משותף; כשהיעד מושג כל החיות בקבוצה מקבלות אביזר ייחודי. דורש טבלאות קבוצות וחברות והזמנות.
- **תמונה שנוצרת ב־AI**: היום העיצוב מורכב מאבני בניין (אמוג׳י, צבע, תכונות). יצירת איור ייחודי דורשת מודל תמונות ואחסון.
